# Imagem de fundo da página inicial

Coloque nesta pasta a imagem da primeira seção do site com o nome exato `fundo.jpg`.

O CSS da página inicial já está configurado para carregar `img/fundo.jpg`, com uma camada escura translúcida para manter os textos legíveis.

Se sua imagem estiver em PNG ou WebP, converta para JPG ou me peça para ajustar o caminho no CSS.
